# โฟลเดอร์นี้คืออะไร

ระบบอัตลักษณ์ของแบรนด์ RubricLensAi — สี ตัวอักษร โลโก้ และหน้าตาของชิ้นส่วน UI

**สถานะ: เฟส 2 เชื่อมระบบแบรนด์เข้ากับ source และ production build ในเครื่องแล้ว**
สีเชิงความหมาย, favicon, ภาพแชร์, metadata และมาสคอตตามสถานะถูกใช้ใน build จริงแล้ว
ข้อความนี้อธิบายความสามารถของ source ไม่ใช่หลักฐานว่า production ถูกอัปเดตแล้ว; ดูสถานะ local/CI/deployment แยกกันที่ `docs/testing-report.md`

---

## เริ่มดูตรงไหน

**ถ้ามีเวลา 2 นาที** → เปิด `preview.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย)
เห็นทุกอย่างพร้อมกันในหน้าเดียว พร้อมสวิตช์ลองโหมดมืด

**ถ้าอยากรู้ว่าทำไมถึงเลือกแบบนี้** → อ่าน `brand-strategy.md`

|------|---------|--------------|
| `brand-strategy.md` | เหตุผลเบื้องหลังทุกอย่าง — บุคลิกแบรนด์ น้ำเสียง หลักการออกแบบ 5 ข้อ | เมื่อทิศทางแบรนด์เปลี่ยน |

| `og/` | ภาพที่โผล่ตอนแชร์ลิงก์ (มี README แยก) | เมื่อเปลี่ยนสโลแกน |

## กฎการแก้ไข

**อยากเปลี่ยนสีทั้งเว็บ** → แก้ค่าอ้างอิงใน `tokens.css` และค่าชื่อเดียวกันใน `src/index.css` ให้ตรงกัน แล้วรัน

```
python docs/brand/verify-contrast.py
```

สคริปต์นี้ตรวจว่าสีที่แก้ใหม่ยังอ่านออกไหมสำหรับคนสายตาไม่ดีและคนตาบอดสี
ถ้าขึ้น "ไม่ผ่าน" แปลว่าสีนั้นจางเกินไป ต้องปรับให้เข้มขึ้นก่อนใช้

**ห้ามเขียนสีตรงๆ ใน `components.css`** — ทุกสีต้องมาจากตัวแปรใน `tokens.css`
ไม่งั้นจะกลับไปเจอปัญหาเดิมคือแก้สีทีต้องไล่ทั้งโปรเจกต์

เว็บจริงเชื่อม token ชื่อ `--rl-*` เข้ากับชื่อเชิงความหมายของ shadcn/Tailwind ใน `src/index.css` เช่น `--primary`, `--background`, `--foreground` และ `--muted` จึงไม่ควรนำชื่อสีเฉพาะไปเขียนกระจายตาม component เพิ่มโดยไม่จำเป็น สีตรงที่ยังเหลือใน `App.tsx` เป็นสีตามหน้าที่เฉพาะ เช่น warning และ informational message ไม่ใช่สีหลักของแบรนด์

## โลโก้ — ใช้ตัวไหนเมื่อไหร่

**โลโก้หลักคือหุ่นยนต์ถือแว่นขยาย** แนวคิดและข้อห้ามอยู่ในหัวข้อ 5 ของ `brand-strategy.md`

**มีตัวละครเดียวทั้งแบรนด์** — มาสคอตหุ่นยนต์ถือแว่นขยาย แบบ 2.5D
ใช้ตั้งแต่ไอคอน 16 พิกเซลจนถึงภาพแชร์ลิงก์ ต่างกันแค่ระดับรายละเอียด
เหมือนคนเดียวกันถ่ายไกลกับถ่ายใกล้ **ไม่มีโลโก้ชุดอื่นอีกแล้ว**

> **"2.5D" คืออะไร:** ภาพเวกเตอร์แบน แต่ใส่ไล่เฉดสีกับแสงเงาจนดูมีปริมาตรเหมือนวัตถุจริง
> ได้ความพรีเมียมแบบ 3D โดยยังย่อขยายไม่แตก ไฟล์เล็ก และแก้สีที่เดียวจบ

### สามระดับรายละเอียด

| ไฟล์ | ใช้ตอนไหน | ขนาดต่ำสุด |
|------|-----------|-------------|
| `logo/mascot-lockup.svg` | มาสคอต + ชื่อแบรนด์ — เอกสาร งานนำเสนอ (เว็บจริงใช้หัวมาสคอตกับชื่อที่เป็นข้อความ) | 44 px |
| `logo/mascot.svg` | มาสคอตเต็มตัว — หน้าจอว่าง รูปโปรไฟล์ ภาพแชร์ลิงก์ | 48 px |
| `logo/mascot-head.svg` | หัวอย่างเดียว — พื้นที่แคบ หัวเว็บบนมือถือ ปุ่ม | 20 px |
| `logo/favicon.svg` | ไอคอนบนแท็บเบราว์เซอร์เท่านั้น | 16 px |

### สี่สีหน้า

| ไฟล์ | ใช้ตอนไหน | ตาเป็นแบบไหน |
|------|-----------|--------------|
| `logo/mascot.svg` | หน้าจอว่าง · สอนใช้งาน · ภาพแชร์ลิงก์ | วงกลมทึบ มองตรง |
| `logo/mascot-thinking.svg` | ระหว่าง AI กำลังตรวจ | เล็กลง เลื่อนขึ้น = เพ่งมอง |
| `logo/mascot-done.svg` | asset สำรองสำหรับสื่ออื่น; เว็บไม่สร้าง state ใหม่เพื่อแสดงภาพนี้ | เส้นโค้งหงายขึ้น = ยิ้มด้วยตา |
| `logo/mascot-offline.svg` | เครือข่าย, บริการ AI หรือระบบหน้าเว็บล้มเหลวจริง | ขีดสั้นสีเทา = จอดับ |

**กฎเหล็ก 2 ข้อ:**

1. **ห้ามให้มาสคอตปรากฏในหน้าผลคะแนน** — คนกำลังดูว่าตัวเองได้กี่คะแนน ไม่ต้องการตัวการ์ตูนมาแสดงความเห็น
2. **`mascot-offline.svg` ใช้กับ "ระบบพัง" เท่านั้น** ห้ามใช้ตอนผู้ใช้ได้คะแนนน้อย — นั่นไม่ใช่ความผิดพลาด

เว็บจริงใช้ `mascot-head.svg` เป็น product identity ในส่วนหัวของหน้าเริ่มต้น/เตรียมข้อมูลและ error ที่ไม่ใช่ system failure, `mascot-thinking.svg` ระหว่างวิเคราะห์ และ `mascot-offline.svg` เฉพาะ error หมวด `network`, `service` หรือ `unexpected` เท่านั้น การเลือกไฟล์ PDF ผิด, validation, quota, compatibility และ idempotency conflict ไม่ใช้มาสคอตออฟไลน์ และหน้าผลคะแนนไม่มีมาสคอตทุกกรณี

### ⚠️ ไฟล์ .svg ทุกไฟล์ในโฟลเดอร์ logo/ ถูกสร้างโดยสคริปต์

**ห้ามแก้ไฟล์ `.svg` โดยตรง — รันสคริปต์ทีเดียวหายหมด**

```
python docs/brand/logo/build-mascots.py
```

สคริปต์จะคัดลอกมาสคอต 3 สถานะที่หน้าเว็บใช้ไป `src/assets/brand/` และ favicon ไป `public/` ให้อัตโนมัติ

เหตุผล: ทั้ง 7 ไฟล์ใช้ "ตัวถัง" เดียวกัน (หัว ตัว แขน แว่น เงา) ต่างแค่สีหน้ากับท่าทาง
ถ้าเขียนแยกด้วยมือ พอวันหนึ่งอยากขยับตาลง 2 พิกเซล ต้องไล่แก้ 7 ที่
และพลาดที่เดียวก็เพี้ยนทั้งชุดโดยไม่มีอะไรเตือน

**ต้องการแก้หน้าตามาสคอต → แก้ที่ `build-mascots.py` แล้วรันใหม่**

### เส้นทาง asset จากต้นฉบับไปเว็บจริง

```text
docs/brand/logo/build-mascots.py
  -> docs/brand/logo/*.svg          เอกสาร/ไฟล์ที่สร้างครบชุด
  -> src/assets/brand/*.svg         มาสคอต 3 สถานะที่ Vite bundle ใช้
  -> public/favicon.svg             ไอคอนแท็บ

docs/brand/og/og.svg + render-og.py
  -> docs/brand/og/og.png           ภาพต้นฉบับที่ render แล้ว
  -> public/og.png                  ภาพแชร์ที่เว็บเสิร์ฟ
```

ห้ามให้เว็บอ้างไฟล์จาก `docs/` ตรง ๆ เพราะ Vite ไม่คัดลอกโฟลเดอร์เอกสารเข้า production build การคัดลอกผ่านสคริปต์ทำให้แหล่งแก้ไขยังอยู่ที่เดียว แต่ runtime asset อยู่ในตำแหน่งที่ระบบ build รับผิดชอบ

### ไฟล์ชุดเก่าที่เลิกใช้แล้ว

อยู่ใน `logo/_retired/` — โลโก้แบบเส้นชุดเดิมทั้งหมด
**ยังไม่ลบ เผื่ออยากย้อนกลับ** ถ้าแน่ใจแล้วว่าไม่ย้อน ลบทั้งโฟลเดอร์ได้เลย

### ข้อจำกัดที่ต้องรู้ (ตรวจพบจากการเรนเดอร์จริงทุกข้อ ไม่ใช่เดา)

1. **`mascot-lockup.svg` ยังไม่ได้แปลงตัวอักษรเป็นเส้น** — มันยืมฟอนต์จากเครื่องที่เปิด
   ใช้บนเว็บเราเองได้ปกติ แต่ถ้าจะส่งโรงพิมพ์หรือให้คนอื่นใช้ ต้องแปลงเป็นเส้นก่อน
   (เคยเจอว่าตัว "i" ตัวสุดท้ายถูกตัดหายเพราะกรอบภาพแคบไป — ตอนนี้ความกว้าง 348 มาจากการวัดจริง
   ถ้าเปลี่ยนขนาดตัวอักษรหรือชื่อแบรนด์ ต้องวัดใหม่)

2. **มาสคอตเต็มตัวที่ต่ำกว่า 48 พิกเซล แว่นกับแผงหน้าอกจะเละ**
   นี่คือเหตุผลที่ต้องมี `mascot-head` และ `favicon` แยก
   **อย่าใช้ `mascot.svg` เป็น favicon เด็ดขาด**

3. **เคยลองใส่ตัวหุ่นลงใน favicon แล้วไม่ผ่าน** — ที่ 16 พิกเซล หัวกับตัวเชื่อมติดกัน
   กลายเป็นก้อนขาวอ่านไม่ออก จึงตัดเหลือแค่หน้าหุ่น

4. **สีใน `favicon.svg` ฝังตายตัว** เพราะไอคอนบนแท็บไม่มีบริบทให้สืบทอดสี
   ถ้าเปลี่ยนสีแบรนด์ใน `tokens.css` ต้องไปแก้ที่ `build-mascots.py` ด้วยมือ

5. **มาสคอตไม่ใช้ `currentColor`** ต่างจากโลโก้แบบเส้นชุดเก่า
   เพราะรูปที่มีแสงเงาต้องใช้หลายเฉดพร้อมกัน จะสืบทอดสีเดียวจากข้อความไม่ได้

6. **ถ้าเอาโค้ดมาสคอตไปแปะในไฟล์ SVG อื่น ต้องใส่ `fill="none"` ที่แท็ก `<svg>` ด้วย**
   มาสคอตมีเส้นจำนวนมากที่ตั้งใจให้มีแต่เส้นไม่มีสีพื้น ถ้าลืม เส้นพวกนั้นจะถูกเติมดำทึบ
   **เคยเกิดจริงตอนทำภาพแชร์ลิงก์ — เลนส์แว่นกลายเป็นวงกลมดำ และขอบหัวมีลิ่มดำโผล่**

7. **ชุดสีไล่เฉด (`<defs>`) ต้องอยู่ที่ระดับรากของไฟล์ ห้ามซ่อนไว้ใน `<g>` ที่ถูกย่อ/ขยาย**

8. **ในคอมเมนต์ของไฟล์ SVG ห้ามพิมพ์ขีดกลางติดกันสองตัว** — ไฟล์จะเสียทันที
